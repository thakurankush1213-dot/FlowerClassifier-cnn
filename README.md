# 🌸 Flower Classification using CNN

A deep learning project that classifies flower images into five different categories using a Convolutional Neural Network (CNN).

## 📌 Project Overview

The objective of this project is to build an image classification model capable of identifying the type of flower from an input image.

The model classifies images into the following five categories:

- Daisy
- Dandelion
- Roses
- Sunflowers
- Tulips
